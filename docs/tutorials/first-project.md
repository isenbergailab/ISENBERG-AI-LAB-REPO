# Your first project

1. Read the [guardrails](../explanation/guardrails.md) and confirm on the signup form.
2. Fork or branch the Lab repo.
3. Create `projects/your-project-slug/`.
4. Copy `templates/PROJECT_README_TEMPLATE.md` into it as `README.md`.
5. Fill in the header. See [Project header fields](../reference/project-header.md).
6. Add a `.env.example` with placeholder keys. Never commit `.env`.
7. Open a pull request. A Senior Dev reviews the code. An officer checks the header.
8. Once merged, your project appears on the open project board.
