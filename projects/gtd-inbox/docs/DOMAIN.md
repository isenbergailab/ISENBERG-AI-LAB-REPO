# Domain terms

Capture: input offered for processing.
Proposal: reviewable suggested change.
Judgment: interpreting meaning or intent.
Bookkeeping: predictable, logged system upkeep.
Private: excluded from remote modeling.
Waiting For: another person's commitment.
Next action: currently available task.
Resolve: close outstanding decision or action.

Jev selects category and multiplicity. GLM extracts source-grounded fields.
Python validates, calculates dates, and enforces approvals.
Feedback replaces pending proposal for review. Feedback alone never authorizes application.

Restricted organizations are locally configured. No employer-specific policy ships here.
Markdown mentions alone are ordinary text. Mark sensitive Markdown as private.
Mail screening checks configured restricted domains. It also checks embedded email addresses.
